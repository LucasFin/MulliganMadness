# Mulligan Madness

Once-per-game **Take All** during card picks, plus a few mutually exclusive auto-pick curses.

## Take All
When enabled (Mods → Mulligan Madness), a **TAKE ALL** button appears on your pick turn. Each player can use it **once per game** — not every round.

Take All grabs the real cards in the current offer, including **Reroll** and **Table Flip** (their usual end-of-pick effects still run).

- **Distill Knowledge** grants the rest of the hand twice and pays Distill’s Nulls twice, without starting the redraw loop.
- **Distill Power** still grants its bonus rares; extra Nulls wait until cards in the **next** pick.
- If Distill already started showing **Nulls**, Take All cashes out the real cards and closes that ritual.

## Curses
Works with WillsWackyManagers curses. You can only have one of these at a time:

| Curse | Effect |
| --- | --- |
| **Forced Choice** | Instantly takes a random offered card |
| **Panic Pick** | Short timer, then auto-picks at random |
| **Leftmost Luck** | Always takes the leftmost card |

## Install
Install with **r2modman** / Thunderstore Mod Manager. Dependencies are pulled in automatically.

Works with common packs (Pick N Cards, PickPhaseImprovements, Genie, Root Curses, WillsWackyManagers). With Pick N Cards set to multiple picks, Take All grabs the **current offered hand** once per game — later picks in that same phase are unchanged.
